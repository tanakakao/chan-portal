# chan-portal

`bochan`、`malchan`、`cauchan` から目的に合う分析ツールを選び、各 Web アプリへ移動するためのポータルです。分析処理やバックエンド処理は持ちません。

## 対象アプリ

| アプリ | 用途 | デフォルト URL |
| --- | --- | --- |
| bochan | ベイズ最適化 | `http://127.0.0.1:5173` |
| malchan | 機械学習 | `http://127.0.0.1:5174` |
| cauchan | 因果分析 | `http://127.0.0.1:5175` |

## 必要環境

- Node.js 18 以上
- npm

## インストールと起動

```bash
npm install
npm run dev
```

ブラウザで `http://127.0.0.1:5172` を開きます。開発サーバーは固定ポート 5172 を使い、使用中の場合は停止します。このプロジェクト単体ではリンク先アプリを起動しないため、各アプリはそれぞれのリポジトリで別途起動してください。

Windows では `start_web.bat` をダブルクリックできます。Node.js と npm、依存パッケージ、ポート 5172 を順に確認してから起動し、エラー時はメッセージを表示したまま待機します。

## 表示モード

画面右上の切替ボタンから、次の表示モードを選択できます。

- **通常**: 既存のシンプルなポータルデザイン
- **8-bit**: 1980年代のゲーム機をイメージしたレトロデザイン

選択した表示モードはブラウザの `localStorage` に保存され、次回アクセス時にも引き継がれます。表示モードを切り替えてもアプリ定義、リンク先URL、URLの利用可否判定は共通です。

## 環境変数

`.env.example` を `.env` にコピーし、必要に応じて URL を変更してください。

```env
VITE_BOCHAN_URL=http://127.0.0.1:5173
VITE_MALCHAN_URL=http://127.0.0.1:5174
VITE_CAUCHAN_URL=http://127.0.0.1:5175
```

未設定の項目には表のデフォルト URL が使われます。空文字または HTTP(S) 以外の不正な URL は無効となり、カードに「URLが設定されていません」と表示されます。

## 新しいアプリの追加

1. `src/config/applications.ts` のデフォルト URL と `applications` 配列に定義を追加します。
2. 必要な `VITE_..._URL` を `.env.example` に追加します。
3. `lucide-react` から用途に合うアイコンを選びます。

カードの描画は設定配列を基に行うため、新しいコンポーネントは不要です。

## 品質確認とビルド

```bash
npm run lint
npm run build
```

ビルド成果物は `dist` に出力されます。`npm run preview` で成果物を確認できます。
